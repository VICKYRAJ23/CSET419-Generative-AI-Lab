# Week 6 – Pix2Pix GAN Image Translation

Objective:
Implement Pix2Pix GAN using U-Net Generator and PatchGAN Discriminator.

Dataset:
CIFAR10 (grayscale → color translation)

Architecture:
Generator: U-Net
Discriminator: PatchGAN

Loss:
Adversarial Loss + L1 Reconstruction Loss

Result:
Pix2Pix generated images are sharper compared to baseline CNN encoder-decoder.
