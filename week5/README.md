# Week 5 – Image-to-Image Translation using CNN

Objective:
Implement a baseline encoder–decoder CNN for image translation.

Dataset:
CIFAR10

Method:
Encoder–Decoder CNN trained using reconstruction loss (MSE).

Tasks Performed:
• Loaded CIFAR10 dataset
• Normalized images to [-1,1]
• Built encoder–decoder CNN
• Trained using MSE loss
• Visualized translated images

Result:
The generated images appear blurry, showing limitations of simple CNN models.
