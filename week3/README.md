## Lab 3: Variational Autoencoder (VAE)

### Objective
To implement a Variational Autoencoder (VAE) to learn latent representations and generate new image samples.

### Dataset
MNIST

### Model
Variational Autoencoder with encoder, decoder, and reparameterization trick.

### Outputs
- Trained VAE model
- Reconstructed images
- Newly generated samples
- Training loss curve
